# DeepGuard

DeepGuard is an app that checks if a video or image is real or fake (deepfake).

## What it does
- Users can upload a photo or video.
- The app uses AI to check if the media has been changed or created by AI.
- It shows a result telling if the media looks real or fake.

## Why we made it
Fake videos and images (deepfakes) are becoming common and can spread false information. DeepGuard helps people quickly check if the media they see online is genuine or not.

## Technology used
- React and TypeScript (frontend)
- Node.js (backend)
- AI/Deep Learning model for detection

## How to run
1. Clone this repository
2. Run `npm install`
3. Copy `.env.example` to `.env` and add your own keys
4. Run `npm start`
